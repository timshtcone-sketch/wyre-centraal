# WYRE Centraal

Opvolging van blazen, lassen en afrekenen per POP-zone voor het WYRE-team.

De gegevens staan in Firebase (Firestore, België) en zijn alleen zichtbaar voor ingelogde teamleden op de toegangslijst. Dit project bevat alleen de webpagina; de Firebase-configuratie hierin is openbaar bedoeld, de beveiliging zit in de Firestore-regels.
